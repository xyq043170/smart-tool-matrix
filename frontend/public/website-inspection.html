网站检测具体包含什么？

直接答案：输入一个公开网址后，检测服务会从服务端请求该站点，并汇总 DNS、TLS 证书、HTTP 状态与响应头、页面标题和描述、技术栈线索、robots.txt 与 sitemap 等公开信息。结果只代表检测时刻的自动观察，不是渗透测试、排名保证或合规认证。

检测项目与可回答的问题

检测项可以看到什么不能据此断言什么
DNS公开 DNS 解析和相关记录线索。不能证明域名控制权或所有内部 DNS 配置。
TLS 证书公开端点返回的证书主体、签发者、有效期等。不能代替完整 TLS 配置审计或证明业务可信。
HTTP 响应状态码、重定向和可见响应头。单次结果不能证明全球节点始终可用。
页面元数据标题、描述、社交元数据等公开 HTML 信息。不能保证搜索引擎一定采用或获得排名。
技术栈线索根据公开资源和响应特征推测的技术。指纹可能误判，不应作为内部架构事实。
robots / sitemap文件是否可访问及其当前公开内容。存在文件不代表所有 URL 已收录或会被索引。

输入、处理和输出

  1. 输入你有权检查的公开 HTTP 或 HTTPS 地址。
  2. 检测服务从服务器侧向目标站点及相关公开端点发送请求。
  3. 页面将多个自动检查结果组织成报告；结果会随 DNS、证书、部署和页面内容变化。
  4. 对重要结论，应使用浏览器开发者工具、DNS/TLS 专用工具或授权安全测试进行复核。

响应时间与可用性

当前检测部署运行在 Render。空闲实例可能冷启动，因此首次打开或首次检测可能比后续请求更慢。本站没有足够的持续测量数据，不提供固定秒数、可用率或性能保证。

安全边界：该工具只用于汇总公开可见信息。不要把结果称为漏洞扫描、渗透测试、隐私合规审计或搜索排名诊断结论。

本站相对 Web-Check 增加了什么

检测能力基于 Alicia Sykes 的开源项目 Web-Check。Smart Tool Matrix 没有原创声明这些检测模块；本站增加的是统一工具目录和账户/额度入口、中文说明、当前部署关系披露、检测边界说明，以及与其他生产力工具的统一导航。Web-Check 项目仍是功能与代码的原始来源。
